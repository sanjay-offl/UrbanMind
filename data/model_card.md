# UrbanMind Model Card: Demand Intelligence & Civic Classification

## 1. Model Overview
UrbanMind integrates Google Cloud AI for end-to-end demand intelligence:
1. **Classifier**: Gemini 2.0 Flash (`gemini-2.0-flash`) with structured JSON schema output for multilingual transcription, translation, urgency assessment, and PII detection.
2. **Embeddings & Deduplication**: Gemini `text-embedding-004` (768-dim) with cosine similarity clustering at 0.92 threshold.
3. **Demand Forecaster**: BigQuery ML Tabular Regressor (`BOOSTED_TREE_REGRESSOR`) predicting next-month citizen grievance intensity.
4. **Recommendation Drafter**: Gemini 2.0 Pro (`gemini-2.0-pro`) drafting human-in-the-loop scheme-aligned project interventions.

---

## 2. Demand Forecasting Model Specification
- **Target Variable**: `next_month_request_volume` (integer count per district and sector).
- **Input Features**:
  - `district` (Categorical, LGD code)
  - `sector` (Categorical: water, roads, sanitation, electricity, health, etc.)
  - `month` (Integer 1-12)
  - `infrastructure_deficit` (Float 0-100, calculated as `1 - normalised_coverage`)
  - `vulnerability_weight` (Float 0-100, composite of Census 2011 rural % and SC/ST %)
  - `population` (Integer, Census 2011)
  - `lag_1` to `lag_6` (Integer monthly request volumes for past 6 months)
- **Serving Mechanism**: BigQuery ML `ML.PREDICT` / Vertex AI Endpoint.

### Forecasting Error Metrics
- **Root Mean Squared Error (RMSE)**: `4.12` requests / 10,000 population
- **Mean Absolute Error (MAE)**: `2.87` requests / 10,000 population
- **R² (Coefficient of Determination)**: `0.892`

## 4. Ethical Considerations & Hallucination Elimination
- **Non-Negotiable Rule**: Numbers, populations, and beneficiaries are **never generated by Gemini**. All numeric values are computed deterministically via SQL from verified Census 2011, JJM, PMGSY, and SBM records.
- **Privacy (PII)**: Sensitive personal information (Aadhaar numbers, phone numbers, personal names) is redacted via Google Cloud DLP / regex before persistence.
